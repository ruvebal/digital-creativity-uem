# Evaluation

Assessment for Digital Creativity I–II. Official weights come from the UEM guía (see track How-to-Pass decks). Studio choreography is parallel with Creativity Techniques: Masterclass → Lab (portfolio) → Workshop (deliverable). This page does **not** rewrite guía percentages.

**Final event theme:** *Communicate and inspire: What is fashion for you?*

## Official weights

Use the current subject guía tables for CD I and CD II (knowledge / case / projects / notebook as published). Studio deliverables below map onto those instruments.

## Session rhythm (every ordinary class)

1. **Analysis strip** — sessions 1–2: modelled analysis; from session 3: **2 × 15 min** student defences  
2. **Masterclass** — ideas + images (accepted course media packs)  
3. **Lab (Portfolio)** — exercises + debates → portfolio index  
4. **Workshop (Deliverable)** — protected time on the next graded deliverable  

**Lab ≠ Workshop.** Names are not swapped.

## 0–10 compatibility

All Digital Creativity rubrics use **0–10** local scores for Campus compatibility. Institutional percentages decide how much each activity weighs in the subject grade.

| Band | Score | Studio evidence |
| --- | ---: | --- |
| Insufficient | 0–4.9 | Missing deliverable, undeclared AI help, no reproducible process, or cannot explain the work |
| Minimum pass | 5–6.9 | Required artefacts present with basic technical and conceptual explanation |
| Competent | 7–8.9 | Complete process evidence, coherent visual decisions, and defensible iteration |
| Excellent | 9–10 | Reproducible workflow, precise critique, strong authorship, and mature technical execution |

## Shared AI and oral defence

AI declarations, project critiques, and oral defences use the same bands. Polish alone is not enough: students must show what they made, what tools assisted them, what they verified, and what they can still explain without the tool present.
