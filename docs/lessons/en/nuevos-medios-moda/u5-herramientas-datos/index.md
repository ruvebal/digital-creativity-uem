**This course is taught in Spanish.** Use the [Spanish lesson]({{ '/lessons/es/nuevos-medios-moda/u5-herramientas-datos/' | relative_url }}) for student-facing work. This page is the English structure twin.

## Master idea

Every metric is a decision about what counts as success: measuring is not proving, and data has an origin, a cost and an owner.

## Learning outcomes

You will separate an indicator from an effect, place any campaign figure on a six-rung evidence ladder, read a sustainability figure or index as a claim that needs method and verification, name the cost of audience data, and write a measurement plan with an explicit red line.

## Portfolio tasks

1. **Dashboard audit.** Audit three KPIs from an account's analytics with the five-question card: what it counts, what it leaves out, who produces it, which decision it drives, which proof is missing.
2. **Measurement plan.** One objective, three indicators on different evidence rungs, the decision each would change, and one red line you would not optimise.

The [AI declaration guide]({{ '/ai-declaration/' | relative_url }}) applies to every portfolio entry.
