## How this addendum attaches to I.7

Parent lesson: [I.7 · Compositional Sources and References in Fashion Design]({{ '/lessons/en/digital-creativity-i/i-7-fashion-references/' | relative_url }}).

I.7 teaches the five-field ledger (source · reason · cultural position · transformation · refusal). This addendum gives you **where to browse** when you refuse anonymous stock packs and AI texture dumps — the instructor’s working source map, verified for live URLs on 2026-11-11, plus Lab exercises that feed the portfolio.

**Course preference:** start in digital repositories (libraries, archives, Commons, museum open-access). Treat stock and AI as ledger-heavy exceptions, never as the default.

## Learning aims

- Name at least six instructor-verified media destinations and what each offers for fashion.
- Browse three repositories, capture platform-page evidence (screenshots + item titles), and write a short fashion-perspective summary per source.
- Index research images into the portfolio with interest notes (why this tile matters to *your* question).
- Draw / complete a provenance graph and a hybrid remix graph using the course taxonomy.

| Class | Short definition | Typical fashion use |
| --- | --- | --- |
| 1 · Digital photograph | Born-digital camera/phone capture | Studio shoot, street style, your own garment photo |
| 2 · Physical scan | Digitised print, plate, textile photo | Historic fashion plates, magazine scans |
| 3 · Computer-generated | CGI, 3D render, vector illustration | CLO/avatar stills, diagrammatic silhouettes |
| 4 · AI-generated | Prompted generative model | Exploration only with prompt/date/refusal fields |
| 5 · Stock / commercial | Marketplace or pack licence | Rare exception — ledger the licence ID |
| 6 · Digital repositories | Libraries, archives, Commons, museum OA | Default for this addendum |

**Hybrid rule:** if you restage, collage, or img2img a class-6 tile, the ledger row becomes hybrid — upstream class + process + tool/date + refusal.

## Lab · Portfolio (research exercises)

### Exercise A · Source atlas (browse → summarise → screenshot) {#lab-exercise-a}

**Time:** 35–45 minutes · **Format:** individual.

**Materials:** laptop; notebook; timer; portfolio folder.

**Steps:**

1. Pick **three** destinations from the Core set (must include at least one of BNE · NYPL · LOC, and at least one of AFA · FRD).
2. For each destination: open the start URL, browse until you can answer — *what fashion perspective does this place privilege?* (period, geography, race, class, industry, gender…).
3. Capture **one platform-page screenshot** (homepage, search results, or collection landing — not a stolen high-res still labelled as yours).
4. Note **two item titles** (essay, plate, object, magazine issue) you could ledger later — titles only if rights are unclear.
5. Write a **120–180 word summary per source**: offer + perspective + one limit (what is missing or over-represented).

**Portfolio trace:** three summaries + three screenshots + six item titles.

**Judged by:** [Portfolio rubric — process evidence]({{ '/assignments/en/digital-creativity-portfolio/' | relative_url }}#rubric)

### Exercise B · Research images → portfolio index {#lab-exercise-b}

**Time:** 25–30 minutes · **Format:** individual.

**Materials:** one cleared or clearly licensed image per source from Exercise A (Commons / OA preferred); I.7 ledger table.

**Steps:**

1. State one research question (one sentence) that continues I.7 Lab 1.
2. Select **three images** from three different destinations — prefer class 6.
3. For each image, fill the five-field ledger **plus** provenance class (1–6) **plus** interest note: *why this image matters to your question*.
4. If rights are only “platform thumb / undetermined,” keep the title in the index and refuse the pixels (write the refusal).

**Portfolio trace:** research question + three ledger rows with interest notes + provenance class tags.

### Exercise C · Provenance graph + hybrid graph {#lab-exercise-c}

**Time:** 20 minutes · **Format:** individual (graphic skills).

**Materials:** paper or vector tool; Graphs A and B above as models.

**Steps:**

1. Redraw Graph A with **your** three Exercise B tiles placed in the correct class boxes (labels + tiny captions).
2. Choose one tile and invent a **hypothetical hybrid path** (CGI restage *or* collage *or* AI img2img) — draw Graph B for that path.
3. Write three lines: what the hybrid gains, what it loses, what you refuse to invent.

**Portfolio trace:** two graphs (photo or export) + three-line hybrid note.

### Exercise D · Optional deep browse (BNE Moda / LOC Frissell / NYPL André) {#lab-exercise-d}

**Time:** 15 minutes · **Format:** optional stretch.

Pick one specialty path:

- BNE: open one digitised moda magazine issue in Hemeroteca Digital and describe how the *figurín* differs from a contemporary lookbook photo.
- LOC: search Toni Frissell + fashion and note how outdoor fashion photography relocates the body.
- NYPL: open the André Fashion Illustrations collection and name one ready-to-wear adaptation logic visible in a drawing.

**Portfolio trace:** one specialty note (≤150 words) + one platform screenshot.

1. Name two differences between a class-5 stock tile and a class-6 Commons tile for fashion reference work.

## Conclusion

Stock and AI are fast; repositories are accountable. Browse the instructor map, index what each place offers for fashion, and let the portfolio show provenance — not just pretty tiles.
