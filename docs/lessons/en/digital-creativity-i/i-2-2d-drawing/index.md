## 🎯 Learning Objectives

- **Describe vector drawing as a relationship** (anchor points, curves, fills) rather than a grid of pixels.
- **State plainly that no vault source validates a specific teaching sequence** for 2D drawing tools — this unit is craft discipline, not cited research.
- **Produce a vector illustration of a simple fashion silhouette** from primitive shapes and paths.
- **Distinguish a tool feature from a transferable drawing concept.**

---

## Why this unit exists — and what it honestly does not have

**Claim:** vector drawing is a discipline of describing shape as a relationship between anchor points and curves — not a discipline of arranging pixels. That claim is taught here as craft discipline, because **the evidence matrix's row for this unit is `NONE`**: no source in this course's vault validates *how best to teach* vector-drawing tools in a fashion-design classroom. Any specific tool's own documentation grounds *how* the software works, never *why this teaching sequence works well* — labelled `[PLATFORM]` wherever it appears, never promoted to a research citation.

### The debate prompt

**Does starting from vector-first (rather than freehand-raster-first) change what a beginner notices about garment silhouette?** No source settles this; the group's own experience in the studio piece is the only evidence in the room today.

## B3 · Resolución de problemas — 1 h · individual, decontextualised

1. **Diagnostic.** Given a vector path with a visibly wrong curve handle, identify what's wrong and what a correct handle would do.
