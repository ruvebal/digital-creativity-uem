## 🎯 Learning Objectives

- **Describe a bitmap image as a fixed grid of colour values** — and explain what a given colour decision (mode, depth, gamut) forecloses for later.
- **State plainly that no vault source validates a colour-editing teaching sequence.**
- **Produce a bitmap composition demonstrating one deliberate colour decision.**
- **Distinguish "colour correction" from "colour change"** — a disclosure question, not a technical one.

---

## Why this unit exists — and what it honestly does not have

**Claim:** a bitmap image is a fixed grid of colour values, and every colour decision — mode, bit depth, gamut — is a decision about what the image *cannot* later become without loss. This is taught as craft discipline: **the evidence matrix's row for I.3 is `NONE`**, no source validates a specific teaching method for colour/bitmap editing. Tool documentation (any raster editor's colour tools) grounds *how* the software works, labelled `[PLATFORM]`, never promoted to a citation.

### The debate prompt

**When does "correcting" a colour become "changing" the garment it depicts?** This is the same disclosure question CD II's retouching unit (II.1) already asks about bodies — asked here at the level of colour. No source settles where the line sits; the group decides it together, and states the decision, rather than assuming it.

## B3 · Resolución de problemas — 1 h · individual, decontextualised

1. **Diagnostic.** Given two versions of the same bitmap at different bit depths, identify which artifact each shows and why.
2. Describe by hand, no tool open, the visual difference between a limited and a full palette for a described image. **No AI — declared as such.**
3. Distinguish "colour correction" from "colour change" for a described edit, using B1's disclosure framing.
