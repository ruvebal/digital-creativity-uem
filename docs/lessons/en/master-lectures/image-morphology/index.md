> **Describe how the image is built before asking what it means.**

**In-class slideshow:** [open deck]({{ '/master-lectures/image-morphology/' | relative_url }})

This is a **Master Lecture** — a transversal visual-literacy method. Use it before the separate [Fashion image analysis master lecture]({{ '/lessons/en/master-lectures/fashion-image-analysis/' | relative_url }}).

</div>

## Learning outcomes

By the end of this master lecture you can:

1. Follow a **morphology pass** (dot → line → plane → shape → form → colour → composition → perspective) and then the **eight-step guide** on one fashion image.
2. Keep **language / medium / support** as three different questions.
3. Separate **conditions of production** from **conditions of reception**, and say how reception can feed the next image.
4. Write one **critical** question with evidence (who appears, who is missing, what desire is sold).

## Why this guide

This lecture does not invent a new CONTENIDOS row. It is a **method workshop** — same spirit as the [Web Analysis Guide](https://ruvebal.github.io/web-atelier-udit/lessons/en/web-analysis/): numbered steps, one sitting, critical emphasis.

It serves campaign analysis, portfolio image work, and any track session that needs a shared critique language.

## B1 · Morphology (in the lesson, not only on slides)

### Morphological reading — before semantics

Before asking what an image means, describe how it is built. Use the shared Digital Creativity sequence:

**dot → line → plane → shape → form → colour → composition → space/perspective**

| Component | What to name | Quick question |
| --- | --- | --- |
| Dot | emphasis, rhythm, attention | Where does the eye stop first? |
| Line | contour, direction, gesture, force | What guides or divides the eye? |
| Plane | fields, layers, figure/ground | Which surfaces organise the frame? |
| Shape | bounded 2D silhouettes | What can be outlined without interpretation? |
| Form | mass, edge, volume, light | What appears flat, folded, or volumetric? |
| Colour | hue, value, saturation, temperature, contrast | What separates, joins, or dominates? |
| Composition | hierarchy, scale, crop, balance, rhythm | How are parts arranged? |
| Space / perspective | depth cues and viewpoint | What makes near/far or projection legible? |

Write one formal claim with visible evidence. Only then continue to origin, context, meaning, critique, and circulation. This is the same morphology pass that prepares I1–I5: image description in I1, drawing in I2, colour in I3, traceable transformation in I4, and perspective/volume in I5.

Kandinsky’s teaching shorthand is useful here: the point is the smallest event of attention, the line records its movement, and the plane receives their relation [(Kandinsky 2012, 9)](#ref-kandinsky-2012). Treat this as a looking order, not a claim that every image is geometric.

When the pass reaches **colour**, keep the same discipline: hue, value, temperature, and contrast act as forces that organise perception, not decoration. Kandinsky’s studio metaphor is exact enough for class — colour as keyboard, the eye as hammer, the soul as a piano of many strings [(Kandinsky 1946, 44)](#ref-kandinsky-1946) — provided students still name visible relations before assigning emotion.

**Teaching move:** keep the vocabulary visible while the image changes. Ask students to compare one plane, one form, one colour relation, and one depth cue before they write a semantic hypothesis. The same terms then travel cleanly into the I2 drawing, I3 colour, I4 transformation, and I5 three-dimensional-form labs.

### Hand-off to the analysis master class

This class stops after formal description. It does not infer genre, meaning, ideology, reception, or circulation. Take the completed morphology card to [Fashion image analysis]({{ '/lessons/en/master-lectures/fashion-image-analysis/' | relative_url }}), where the eight-step critical method begins.

### Morphology card — stop before interpretation

| Pass | Observable vocabulary | Prompt |
| --- | --- | --- |
| 1 | Dot, line, plane | Where are attention, direction, and figure/ground organised? |
| 2 | Shape, form, light | Which silhouettes, edges, folds, and volumes can you point to? |
| 3 | Colour, composition | How do hue, value, scale, crop, rhythm, and balance relate? |
| 4 | Space, perspective | What makes depth, viewpoint, overlap, or projection legible? |

**Stop here.** Meaning, genre, ideology, reception, and circulation belong to the separate analysis master class.

### Studio exercise: formal inventory

Choose one image and produce eight short observations, one for each morphology term. Each observation must point to a visible location, relation, or change. Do not write a message, genre claim, or audience interpretation yet.

## Masterclass ideas (six)

1. Dot and line.
2. Plane and shape.
3. Form and light.
4. Colour relations.
5. Composition and crop.
6. Space and perspective.

## B2 · Lab (portfolio)

### Exercise 1 — Shared image

Fill the **morphology card** on the image the professor models. Include one visible observation for every component.

### Exercise 2 — Your image

Choose an image from a campaign, lookbook, or feed post. Complete the morphology card only; carry it to the separate analysis class afterward.

Everything goes to the portfolio index / Canvas. It can feed campaign analysis or any track unit that needs visual critique.
