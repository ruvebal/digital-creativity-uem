## Learning aims

- Treat \(x/z\) projection as Alberti’s window written in algebra.
- Name virtual camera = station point + picture plane.
- Separate 2.5D (sort/occlusion) from stereo / Z-buffer honesty.
- Ask the AI plausibility question without Midjourney scrapes.
- Bridge back to I.6: behaviour diagnosis still required.

## Masterclass (five moves)

1. **Projection \(x/z\)** — flat output from a ratio, not from “3D vibes.”  
2. **Virtual camera = Alberti** — same cut through the pyramid, different UI.  
3. **Z-buffer / stereo** — when occlusion is *tested*, not painted.  
4. **AI plausibility** — a fold can look right and still invent support.  
5. **Bridge to I.6** — classify the engine, then run a fit/drape test.
