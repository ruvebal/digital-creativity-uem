## Learning aims

- State the retina paradox: a 2D array supports many 3D interpretations.
- Separate Helmholtz-style inference from Gibson-style ecological optics as *studio frames*, not exam dogma.
- Inventory pictorial cues (occlusion, relative size, perspective, texture, aerial) without claiming fashion-HE RCTs.
- Hand a studio ask back to I.5: which cue is your multi-view test using?

## Masterclass (six moves)

1. **Paradox** — The same silhouette can hide several honest volumes.  
2. **Inverse problem** — Perception recovers depth that the picture underdetermines.  
3. **Helmholtz frame** — Unconscious inference from prior experience (orientation).  
4. **Gibson frame** — Ambient optic array and motion parallax (orientation).  
5. **Cue table** — Occlusion · size · linear perspective · texture gradient · aerial.  
6. **Studio ask** — Pick one fashion still; name three cues; say what fit they cannot prove.
