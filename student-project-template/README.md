# Student project template — Creación Digital

Scaffold for student repositories (CD I / CD II).

Suggested spine:

```
research/     brief, references, consent notes
design/       looks, mood, avatar decisions
production/   exports (glTF, stills), web pages
exhibition/   portfolio URL, vShowroom piece ids
evaluation/   process narrative, AI-use declaration
```

Fill this template as the first units land. Until then, keep exports local and consent-ready.
