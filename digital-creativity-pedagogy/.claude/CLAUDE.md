# Profield curriculum evidence rules

Use `docs/AI-CURRICULUM-HARNESS.md` as the operating contract.

- Audit every attached field artifact separately and name every run ID.
- State whether the actual FieldSpec was supplied; do not infer compliance from
  an embedded prompt.
- Distinguish a structural audit from registry verification and source/page
  verification. Never claim a citation was externally verified unless it was.
- Return an exact edit ledger and a separate verification queue. Preserve
  `[BIBLIO-GAP]` rather than repairing a missing source with plausible prose.
- Classify HE, practitioner and platform evidence separately. Do not convert
  emerging practice into settled pedagogy.
