# Creación Digital I–II · 120-minute session prompts

These instructor guides are the first filled pass of the session forge in
[`SESSION-PROMPT-FORGE.mdc`](./SESSION-PROMPT-FORGE.mdc). Each guide is one
2-hour classroom meeting, not an invented institutional date or timetable.
The official activity allocations remain in [`docs/_data/tracks.yml`](../../docs/_data/tracks.yml)
and the authoritative contents/competency/hour contract remains in
[`oficial-guia-framework.mdc`](../oficial-guia-framework.mdc).

All guides request three media roles: a short video, a classified still-image
set, and an explanatory graphic. The licence and semantics fields are
deliberately explicit so the future Profield prospector can fill them without
turning search results into unverified teaching assets.

Each guide is now also governed by the [critical field/subfield layer](./CRITICAL-FIELD-LAYER.md):
one situated tension, one verified Ahmes perspective where available, and one
open living prompt that the class revisits with evidence.
