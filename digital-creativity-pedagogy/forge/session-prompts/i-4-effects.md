## Context & learning goals

Define an effect as a transformation with a communicative job, not a catalogue
of filters. Students will name an intended perceptual change, compare reversible
and destructive operations, explain a before/after difference, and critique an
effect for accessibility and authorship.

## Session A: Effect as an argument (2 hours)

| Time | Teacher move |
| --- | --- |
| 00–10 | Reveal a before/after in five seconds; students write what they think the effect argues. |
| 10–30 | Explain adjustment, compositing, masking, blend, distortion, and temporal effects as families. |
| 30–45 | Screen a short effect breakdown; pause before the reveal and ask students to predict the layer logic. |
| 45–55 | Compare an expressive exemplar with a decorative counterexample; discuss legibility and restraint. |
| 55–65 | Demo a reversible layer stack, naming source, mask, effect, and export. |
| 65–100 | Studio sprint: one before/after pair with kept "before" and one-line disclosure (lesson B2). |
| 100–113 | Individual B3, no AI: follow lesson page — missing "before", hand-written disclosure, effect vs manipulation. |
| 113–120 | Peer “keep / reduce / remove” feedback and process save. |

## Screening & analysis

- **Video:** legal effect breakdown or public-domain trick-film excerpt; annotate
  the transformation, not the software brand.
- **Stills:** purposeful effect, over-effected counterexample, and accessible
  alternate; ask what remains readable.
- **Graphic:** layer-stack diagram `source → mask → transformation → compositing
  → verification → export`, with a reduced-motion note.

## Studio sprint

Deliver one before/after pair (lesson B2): deliberately applied effect, kept
"before", one-line disclosure, piece ID, and process folder. Optional stretch:
a second brief variant if time allows — assessment still scores the disclosed pair.

## Individual problem

Follow the lesson page B3 items (authoritative for assessment):

1. **Diagnostic, no AI:** given an "after" image with no "before" kept, name what's missing from an honest effects workflow.
2. Write the one-line disclosure by hand for a described effect, no tool open.
3. Distinguish "effect" from "manipulation" for a described case, using B1's disclosure framing.

## Critical field lens & open living prompt

**Field tension:** an effect can clarify material evidence or manufacture a more
desirable body, garment, or world while appearing merely technical.

**Critical perspective:** Which changes need disclosure, consent, or refusal, and
who has authority to decide that threshold?

**Open living prompt:** At what point does transformation become a claim about a
person, garment, or reality rather than a visual treatment?

**Bring forward:** one before/after, edit-ledger entry, or refusal case.
