## Context & learning goals

Treat the tool as a means for controlling line, shape, layer, and revision.
Students will distinguish raster from vector behaviour, select a drawing tool
for a communicative purpose, build a small fashion line study, and document a
revision rather than presenting only the final image.

## Session A: Line, path, layer (2 hours)

| Time | Teacher move |
| --- | --- |
| 00–10 | Show three line studies and ask which suggests structure, gesture, or texture. |
| 10–30 | Explain raster/vector, path/brush, layers, selection, transform, and reversible edits. |
| 30–45 | Screen a licensed drawing-process video; students freeze-frame the moment a decision changes. |
| 45–55 | Compare a clean exemplar with an overworked counterexample using a line/shape rubric. |
| 55–65 | Live demo: build a garment contour with a named layer stack and two reversible revisions. |
| 65–100 | Studio sprint: create three 2D line treatments for one garment detail; peer critique chooses the clearest. |
| 100–113 | Individual B3, no AI: choose raster or vector for three stated tasks and justify. |
| 113–120 | Exit ticket and save a versioned process file plus flattened preview. |

## Screening & analysis

- **Video:** screen capture or open drawing demonstration; students annotate
  cursor/tool choice, not brand loyalty.
- **Stills:** vector-like contour exemplar, raster texture exemplar, and a
  counterexample where effects obscure the silhouette.
- **Graphic:** a `brief → line → layer → revision → export` loop with raster and
  vector branches and a text-only alternative.

## Studio sprint

Make three labelled treatments of one garment detail: contour, construction,
and texture. Submit editable source, flattened PNG, a layer/path inventory,
and a two-sentence rationale. Use a keyboard/mouse-neutral route and provide
a high-contrast view.

## Individual problem

Follow the lesson page B3 items (authoritative for assessment):

1. **Diagnostic, no AI:** given a vector path with a visibly wrong curve handle, identify what is wrong and what a correct handle would do.
2. Describe, in writing with no tool open, how to construct a simple vector shape from primitives.
3. Explain why "I drew it in a raster app" would not satisfy this unit's CONTENIDOS anchor.

## Critical field lens & open living prompt

**Field tension:** tool fluency can reward prior access to hardware, software,
and studio conventions rather than only drawing judgement.

**Critical perspective:** Who can afford the “normal” workflow, and which line
qualities are treated as professional by default?

**Open living prompt:** When does a clean digital line describe craft, and when
does it hide a particular tool, labour, or default aesthetic?

**Bring forward:** one low-tech alternative, access barrier, or counterexample.
