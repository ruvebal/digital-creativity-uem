## Context & learning goals

Make time, repetition, anticipation, and change the material of the image.
Students will describe a motion intention, place keyframes or frames with
purpose, build a short loop, critique timing and readability, and export an
accessible static fallback. **B3 is 0 h — individual evidence lives in B2's process note.**

## Session A: Frame, interval, loop (2 hours)

| Time | Teacher move |
| --- | --- |
| 00–10 | Play a three-second loop twice; ask why the second viewing reveals a different event. |
| 10–30 | Explain frame/interval, keyframe, easing, anticipation, repetition, loop, and file weight (Shaw 2015 framing). |
| 30–45 | Screen a legal animation or fashion-motion clip; students chart three timing changes. |
| 45–55 | Compare a readable loop with a technically busy counterexample; discuss reduced motion. |
| 55–65 | Demo a six-keyframe loop and a static storyboard fallback. |
| 65–100 | Studio sprint: animate one garment detail (lesson B2) with process note + static fallback. |
| 100–113 | Reflective writing in process note (no separate B3): keyframe rationale and img-002 paradox. |
| 113–120 | Quiet playback, peer note, save source and export. |

## Screening & analysis

- **Video:** short stop-motion, motion-graphics, or fashion-film excerpt;
  annotate interval, anticipation, and loop seam.
- **Stills:** storyboard, first/last frame, and a reduced-motion/static version.
- **Graphic:** timeline showing `setup → anticipation → action → settle → loop`,
  plus a text-only frame list.

## Studio sprint

Create one short animated image, one static fallback, a six-frame or keyframe
plan, and a process note that carries individual-evidence weight (B2/B3 collapse).
Preserve source assets and licence evidence for any non-original element.

## Individual problem

**No separate B3 this unit (0 h).** Embed in B2 process note:

- Which stills were chosen and why.
- One reduced-motion or static alternative and what it retains.
- One sentence on rhythm/exclusion (critical lens).

## Follow-up

## Critical field lens & open living prompt

**Field tension:** motion attracts attention but can accelerate consumption,
hide labour, or exclude viewers sensitive to movement.

**Critical perspective:** Who is the rhythm designed for, and what does the loop
make us overlook?

**Open living prompt:** When does animation create agency and attention, and
when does it make the viewer perform the platform's demand for speed?

**Bring forward:** one reduced-motion alternative, labour trace, or excluded viewer.
