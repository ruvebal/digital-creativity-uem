## Context & learning goals

Treat the portfolio as a designed publishing system: selection, sequence,
context, authorship, accessibility, and maintenance. Students will map an
information architecture, publish one responsive case study, disclose tools and
materials, and distinguish visibility metrics from evidence of quality.

## Session A: Portfolio as evidence (2 hours)

| Time | Teacher move |
| --- | --- |
| 00–10 | Show two portfolio home pages; ask which one makes process and authorship verifiable. |
| 10–30 | Explain audience, IA, case study, hierarchy, responsive layout, alt text, authorship, and maintenance. |
| 30–45 | Screen a legal portfolio walkthrough; students note navigation, evidence, and access barriers. |
| 45–55 | Compare a visual-only page with a process-rich page; discuss what each can and cannot prove. |
| 55–65 | Demo a one-case responsive page with semantic headings, alt text, credits, and tool declaration. |
| 65–100 | Studio sprint: teams critique an IA, then each student drafts one case-study page. |
| 100–113 | Individual B3, no AI: repair a page with missing context, inaccessible contrast, or unclear authorship. |
| 113–120 | Peer test on a clean browser/device and record one friction point. |

## Screening & analysis

- **Video:** portfolio/process walkthrough with transcript; annotate audience,
  navigation, case-study evidence, and maintenance assumptions.
- **Stills:** accessible case-study exemplar, image-only counterexample, and a
  responsive/mobile view; use only cleared references.
- **Graphic:** IA wireframe `home → selected work → case study → process → about /
  contact`, plus an authorship/licence declaration block.

## Studio sprint

Build one responsive case-study page or a paper/HTML prototype. Include brief,
role, process evidence, final output, tools/materials declaration, credits,
alt text, keyboard path, and a plain-text fallback. S1/S2 is required before
any public showroom use.

## Individual problem

1. **Diagnostic, no AI:** choose the first repair for a page that is beautiful
   but unclear, inaccessible, or unauthored.
2. Distinguish a portfolio claim from the evidence that supports it.
3. Write a tool/material declaration for a page that includes AI-assisted work.
