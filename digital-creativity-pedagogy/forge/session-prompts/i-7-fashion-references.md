## Context & learning goals

Teach moodboards as accountable research objects, not image piles. Students
will trace a reference to its canonical source, classify its compositional
function, write a transformation plan, and distinguish inspiration, quotation,
adaptation, and infringement as practical studio decisions.

## Session A: Reference, trace, transform (2 hours)

| Time | Teacher move |
| --- | --- |
| 00–10 | Show a moodboard with and without credits; ask which one can be trusted. |
| 10–30 | Explain source hierarchy, visual function, citation, transformation, and provenance. |
| 30–45 | Screen a licensed archive/reference-research video; stop when a source becomes a design move. |
| 45–55 | Audit two boards for traceability, diversity, and compositional usefulness. |
| 55–65 | Demo a reference ledger: source, licence, visual property, intended transformation, result. |
| 65–100 | Studio sprint: create a 3–6 item board (lesson B2) with representational-pattern reflection. |
| 100–113 | Individual B3, no AI: follow lesson page — missing attribution, hand-written pattern reflection, inform vs copy. |
| 113–120 | Peer check: another student must be able to reconstruct two sources. |

## Screening & analysis

- **Video:** museum, archive, or designer research process with rights-cleared
  access; annotate source-to-decision transitions.
- **Stills:** credited exemplar, visually strong but untraceable counterexample,
  and a public-domain source with clear metadata.
- **Graphic:** `source → visual property → transformation → new composition → credit`
  and a text-only ledger.

## Studio sprint

Produce a board with creator, canonical URL, licence/permission,
visual property, transformation verb, and an original synthesis. No asset enters
the board without a provenance record. Provide captions and a screen-reader list.

## Individual problem

Follow the lesson page B3 items (authoritative for assessment):

1. **Diagnostic, no AI:** given a board with no attribution and no reflection note, name what's missing.
2. Write the one-sentence representational-pattern reflection by hand for a described board.
3. Distinguish "a reference that informs" from "a reference that is copied."

## Critical field lens & open living prompt

**Field tension:** reference boards can turn archives and cultural knowledge
into uncredited extraction.

**Critical perspective:** Whose context, agency, and right not to be reused are
missing when a source becomes a moodboard tile?

**Open living prompt:** How can a reference remain useful while preserving the
source's context, agency, and right not to be reused?

**Bring forward:** one source-context note, refusal case, or transformed reference.
