## Context & learning goals

Design the visitor journey before decorating the interface. Students will map
entry, observation, interaction, reflection, and exit; compare multiple views
and close-ups; prototype one experience path; and identify the difference between
engagement evidence and a claim that learning occurred.

## Session A: Experience as choreography (2 hours)

| Time | Teacher move |
| --- | --- |
| 00–10 | Give students a silent digital-tour screenshot; ask what action is invited first. |
| 10–30 | Explain audience, object, viewpoint, affordance, pacing, sensory cue, and reflection. |
| 30–45 | Screen a legal digital fashion exhibition tour; pause for observation and reflection time. |
| 45–55 | Compare a guided path with an overwhelming interface; name what is measurable. |
| 55–65 | Demo a journey map with object view, close-up, prompt, and return path. |
| 65–100 | Studio sprint: prototype a three-step fashion-object experience on paper or web. |
| 100–113 | Individual B3, no AI: Kim prediction; staging rationale; unresolved metaverse boundary. |
| 113–120 | One-minute visitor walkthrough and peer observation note. |

## Screening & analysis

- **Video:** narrated digital exhibition tour; students log object view, close-up,
  pause, prompt, and reflection opportunity.
- **Stills:** interface with clear orientation, detail view, and a counterexample
  that hides the object behind decoration.
- **Graphic:** journey map `enter → orient → inspect → compare → reflect → exit`,
  with a no-device storyboard fallback.

## Studio sprint

Deliver a three-step prototype, object description, audience assumption, one
accessibility accommodation, and an observation/reflection prompt. If the item
may be exhibited, attach unsigned S1/S2 drafts for later administration; drafts
are not permission.

## Individual problem

1. **Diagnostic, no AI:** given two stimulus-type descriptions for the same show (screened recording vs. 360° capture), predict which Kim's finding suggests produces a stronger response, and say in one sentence why that is a prediction, not a guarantee.
2. Write a one-paragraph staging rationale, by hand, for a described experience concept.
3. **No-AI, declared:** explain in one sentence why an unresolved metaverse reference is not used as evidence in this unit.

## Follow-up

Run the prototype with one peer as a design critique only; do not retain or
analyse participant data as research. Revise the journey map from observed friction.

## Critical field lens & open living prompt

**Field tension:** experience design choreographs attention and can confuse
engagement with learning, value, or consent.

**Critical perspective (C1):** Digital mediatization of fashion reaches runway
design, retail, and everyday self-fashioning — not only campaign communication.

**Critical perspective (C2):** Virtual fashion shows can widen access but also
create friction; format innovation does not guarantee legibility for every audience.

**Open living prompt:** When does a digital tour widen access, and when does it
replace the object, institution, or community with a thinner experience?

**Bring forward:** one access route, visitor burden, or absent voice.
