## 0. Medium law (agency decision)

Web diffusion means we *may* use motion and real depth — but CD I must not steal CD II’s subject.

| Medium | Use when | Do **not** use when |
| --- | --- | --- |
| **Static SVG / TikZ plate** | One pedagogical claim must freeze for caption, deck `diagram_src`, reduced-motion, print twin | Hero band; “feel the volume” without a named variable |
| **Canvas 2.5D** (canvas-25d) | Pointer-literate depth *sorting* of SVG-derived facets; landing/lesson heroes; cue diagrams that benefit from flotation without a depth buffer | You need occlusion, lighting, or mesh deformation as the lesson claim |
| **Rive + AnimaScript 3D** (platonic / svg-to-rive / rive-animascript) | Authored state machine + true-ish volume mark; Dürer machine / measuring-rod glyph; favicon family; **hero marks** | Full scene, cloth sim, camera flythroughs that belong in CD II |
| **WebGL open space** (Three/R3F-class) | **CD II only** as the main teaching surface | CD I Volume–Depth series as the *primary* illustration (preview teaser ≤1 lab optional, labelled “CD II preview”) |

### Decision rule (one line)

**If the student must *read a construction*, ship SVG (+ optional 2.5D).**  
**If the student must *feel a solid as identity/hero*, ship platonic Rive / Canvas 2.5D.**  
**If the student must *inhabit a scene*, that is CD II — park it.**

### Dare: platonic-solids — **yes, off the landing**

The skill is forge-indexed and Bertol-gated. Use **`FAVICON-RIVE-3D` / projected Canvas 2.5D** for lesson/track/lab heroes and Volume labs — orbitable pointer response, frontal rest, SVG twin. **Landing stays the signature faceted brand mark.** Teaching *cloth behaviour* stays diagram + photography, not a soft-body WebGL demo in CD I.

### Rive vs WebGL in this series

| Surface | Choice |
| --- | --- |
| Landing / lesson / track **heroes** | platonic mark → Rive state machine *or* Canvas 2.5D projected facets; SVG twin always |

## 2. Design system — “Bauhaus × neo-Renaissance atelier”

One visual language across all new plates:

| Token | Rule |
| --- | --- |
| Paper | `#F7F2E8` (light teaching) · dark twin via hex-color-tools invert-lightness for night decks only |
| Ink | `#111111` primary · `#24344D` construction · `#B45B43` accent (measure / error) · `#C49337` highlight |
| Line | Hairline construction (0.75–1.25 px @1600) + one bold claim stroke (3–4 px) |
| Type | No Inter-as-UI. Display: one grotesque Bauhaus for labels; captions as caption, not card chrome |
| Layout | Full-bleed diagram plane — **kill rounded cards** and three equal “app panels” unless the pedagogy *is* comparison |
| Depth | Orthographic first; true perspective only when teaching perspective |
| Uniqueness | One recurring studio glyph: **measuring rod + vanishing pin** (platonic-derived mark, not φ-Mondrian) |

**FEI track hero pattern to port:** full-viewport `hero-section--archive` / landing mark hierarchy; formula-led figure with fractal backdrop credit; `h1` as composition focal after the mark — see web-atelier FEI track + landing.

**Landing upgrade targets (DC vs web-atelier):**

| Token | DC now | Target (atelier) |
| --- | --- | --- |
| `--landing-mark-max` | `15rem` | `20rem` |
| `--landing-mark-size` | `clamp(8rem, 24vmin, …)` | `clamp(9rem, 28vmin, …)` |
| `#hero-title` | `clamp(1.75rem … 3rem)` | `clamp(1.8rem … 3.25rem)` (+ mark owns focal weight) |
